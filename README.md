# 🌿 Critter Pop · 萌宠开心消消乐

A Smiling Critters Match-3 puzzle adventure inspired by **《开心消消乐》 (Anipop)**! Climb the 8-Level Giant Vine Tree, match cute Critter Heads, synthesize **Line Blasts (`⚡`)**, **3×3 Area Bombs (`💣`)**, and **CraftyCorn Magic Birds (`🌈🦄`)**, shatter **Frost Ice (`🧊`)**, and harvest **Golden Honey (`🍯`)**!

**Play Live:** [https://kunruiw1991.github.io/critters-match3/](https://kunruiw1991.github.io/critters-match3/)

---

## ✨ Iconic 《开心消消乐》 Features

1. **6 High-Contrast Smiling Critter Candy Tiles**:
   - 🟠 **DogDay · 日犬** (`☀️`) · 🟣 **CatNap · 瞌睡猫** (`🌙`) · 🔴 **Bobby BearHug · 抱抱熊** (`❤️`)
   - 🔵 **Bubba Bubbaphant · 聪聪象** (`💧`) · 🟢 **Hoppy Hopscotch · 跳跳兔** (`🍀`) · 🟡 **KickinChicken · 酷酷鸡** (`⭐`)
2. **Full Special Bomb Synthesis & Super Combos (`特效合成与双特效大招`)**:
   - **4-in-a-Row (`四连直线特效 ⚡`)**: Clears an entire horizontal row (`↔️`) or vertical column (`↕️`) with a laser beam!
   - **T / L Shape 5-Match (`T/L型爆炸特效 💣`)**: Detonates a `3×3` shockwave around the tile!
   - **5-in-a-Row (`五连魔力鸟 🌈🦄`)**: Spawns **CraftyCorn Magic Bird**! Swap it with any Critter to clear **all tiles of that Critter across the entire 8×8 board**!
   - **Special + Special Swap (`双特效交换`)**: Swap `🌈 + ⚡/💣`, `🌈 + 🌈`, `⚡ + 💣`, or `💣 + 💣` for screen-clearing mega combos!
   - **Direct Double-Tap Detonation**: Double-click/tap any `⚡`, `💣`, or `🌈` tile on the board to detonate it anytime!
3. **8 Giant Vine Tree Levels (`藤蔓大树8大闯关`)**:
   - Features **1-Layer & 2-Layer Ice Blocks (`🧊 / ❄️`)**, **Golden Honey Jars (`🍯`)**, and Critter collection goals.
   - **Casual Never-Stuck Mode (`♾️ 轻松不败模式`)**: Running out of moves automatically gifts `+10 Free Moves`, plus **4 Unlimited Free Boosters** (`🔨 Hammer`, `🌈 Color Wand`, `💣 Spawn Bombs`, `🔀 Shuffle +5 Moves`)!
